# Sillytavern-Openrouter-ProviderRouting
Pinning varied providers and fallbacks in order for varied models.

No more providers being stuck in the last state as you switch between models.

Covers a wide range of models, from GLM 4.6-5.3 (except 5), Kimi k2.5 to k3, Opus 4.6, Deepseek R1, v3.1 Terminus, v3.2, gemini 3.7 and 3.8 flash, among a few others.

You can edit index.js and fork this to add your own providers and fallbacks for your own models.
